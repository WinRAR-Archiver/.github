## 🧠 Overview

WinRAR is a Windows file archiver that packs files into RAR or ZIP containers and unpacks almost any common archive format in return. The shell integration adds context-menu actions for compressing to a chosen profile, extracting to a named folder, testing an archive, or converting an existing ZIP into RAR without unpacking it by hand.

Archive work is organised around profiles: compression method, dictionary size, solid-archive mode, volume size and password are stored together, so repeatable backups and distribution packages are created with identical settings. Recovery records, archive comments, file filters and SFX module generation are handled in the same dialog, and the built-in viewer opens packed files without extracting them to disk.

## Additional Information for Windows Users

Compression result depends on the data: already-compressed media such as JPEG, MP4 or archives gains little, while text, logs, databases and source trees shrink noticeably with the maximum method. Solid archives compress better but extract slower and prevent extraction of a single file without reading the preceding blocks.

Multi-volume sets must be kept complete and in order: a missing volume stops extraction at that point, and recovery volumes only repair damage, not absence. Passwords are not stored in the archive, so an encrypted set without the password cannot be restored by the application itself.
